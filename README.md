# EEGWorkshop_BXLCuttingGarden
BXL Cutting Garden 2026 - Workshop

## Introduction to EEG
Two-day hands-on workshop introducing the fundamentals of electroencephalography (EEG), from acquisition and preprocessing to basic analysis and visualization.

## Objectives
- Understand the basic principles of EEG
- Understand EEG acquisition and electrode placement
- Load and visualize EEG data
- Identify common EEG artifacts
- Perform standard preprocessing
- Extract and visualize EEG features
- Perform standard time- and frequency-domain analyses

## Program
**Day 1 — From EEG to clean data**  
S1 — Theoretical introduction   
*What's an EEG? What's preprocessing? How can we look at the neural signal?*   
S2 - Hands-on EEG setup  
S3 & S4 - Diving into preprocessing    
*Discovering MNE-Python / Introduction to BIDS*   
*Preprocessing + basic signal processing in practice*      

**Day 2 — From clean data to neuroscience**     
S5 & S6 — Signal processing  
*Event-related potentials (ERP)*    
*Time-frequency analysis*   
S7 & S8 — Signal processing   
*Source reconstruction*   
*Source-level analysis*      
*Decoding*     
*Other cool stuff*
